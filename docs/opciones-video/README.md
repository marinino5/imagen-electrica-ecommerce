# Opciones de video para la primera diapositiva del hero

La primera diapositiva es lo primero que ve la gente: tiene que ser nítida, bien iluminada y con movimiento claro. Se descartó el video anterior (primer plano oscuro y desenfocado de un rotor, Pixabay id-41477). Se revisaron Mixkit y Pixabay con «conveyor belt factory», «industrial production line», «electric motor factory», «packaging machine» y «assembly line» (más de 40 clips vistos fotograma a fotograma).
